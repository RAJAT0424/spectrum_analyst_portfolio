# Data Analyst Portfolio — Cable Broadband (Spectrum-style) Projects

Two end-to-end projects built on realistic, **synthetic** data modeled on a U.S. cable broadband company.

| # | Project | Business question | Skills shown |
|---|---|---|---|
| 1 | `project1_churn/` — Internet Churn & Retention | Why do customers leave, who leaves next, which save offer works? | SQL cleaning & joins, feature engineering, logistic regression / random forest, A/B testing, Power BI |
| 2 | `project2_care_ops/` — Care & Field Operations | How do we cut avoidable truck rolls and outage call spikes? | SQL window functions & time-window joins, contact-center KPIs, cost modeling, Power BI |

Each folder has: `data/` (CSVs), `sql/` (full query walkthrough), a `README.md` with the scenario, step-by-step plan, dashboard layout, answer key, resume bullets and interview pitch. Project 1 also has `python/churn_model.py`.

`generate_data.py` re-creates every dataset (Python + pandas + numpy, seed 42).

Suggested timeline: Project 1 in ~2 weekends, Project 2 in ~1–2 weekends. Publish both to GitHub with dashboard screenshots and link them on your resume and LinkedIn.

*All data is fictional and not affiliated with Charter Communications.*
